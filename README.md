# Password Generator

Ferramenta simples para gerar senhas seguras, disponível tanto via linha de comando (CLI) quanto interface web.  
Página web: [https://fantonelli.com/pass-generator](https://fantonelli.com/pass-generator)

## Funcionalidades

- Gerar senhas aleatórias de forma rápida.
- Escolher tamanho da senha.
- Interface web intuitiva para usuários leigos.
- Funciona offline via CLI.
- **Validações na web são realizadas apenas do lado cliente**, diretamente no navegador.

## Como usar

### CLI (Python)

```bash
# Clone o repositório
git clone https://github.com/seuusuario/password-generator.git
cd password-generator/cli

# Execute o script
python3 generate_password.py
